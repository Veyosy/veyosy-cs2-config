# Veyosy CS2 Config — v1.0

Initial public release of my personal Counter-Strike 2 config.

## Included

- `autoexec.cfg`
- custom binds
- crosshair settings
- viewmodel settings
- radar / HUD settings
- sound settings
- gameplay preferences
- installation guide

## Main values

- Sensitivity: `1.0`
- Zoom sensitivity: `1.0`
- Viewmodel FOV: `68`
- Viewmodel offsets: `2.5 / 2.0 / -2.0`
- FPS limit: `999`
- UI FPS limit: `200`

## Install

Place `autoexec.cfg` in:

```text
...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
```

Then launch CS2 and execute:

```text
exec autoexec
```

or add this to Steam launch options:

```text
+exec autoexec.cfg
```
