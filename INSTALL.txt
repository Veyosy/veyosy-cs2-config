VEYOSY CS2 CONFIG — INSTALL

1. Copy autoexec.cfg to:
   ...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\

2. Start CS2.

3. Open console and enter:
   exec autoexec

Optional Steam launch option:
   +exec autoexec.cfg

Successful load message:
   [AUTOEXEC] Veyosy config LOADED
