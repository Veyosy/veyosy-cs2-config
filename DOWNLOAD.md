# Download

## Latest stable version: v1.0

Download the config directly:

- [`autoexec.cfg`](https://raw.githubusercontent.com/Veyosy/veyosy-cs2-config/main/autoexec.cfg)

Or download the whole repository as ZIP:

- [`veyosy-cs2-config-main.zip`](https://github.com/Veyosy/veyosy-cs2-config/archive/refs/heads/main.zip)

After downloading, place `autoexec.cfg` into:

```text
...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
```
