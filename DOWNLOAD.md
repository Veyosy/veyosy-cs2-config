# Download

## Latest stable version: v1.0

Download the stable config directly:

- [`autoexec.cfg`](https://raw.githubusercontent.com/Veyosy/veyosy-cs2-config/v1.0/autoexec.cfg)

Or download the complete v1.0 snapshot as ZIP:

- [`veyosy-cs2-config-v1.0.zip`](https://github.com/Veyosy/veyosy-cs2-config/archive/refs/heads/v1.0.zip)

After downloading, place `autoexec.cfg` into:

```text
...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
```

Then launch CS2 and run:

```text
exec autoexec
```

or add this to Steam launch options:

```text
+exec autoexec.cfg
```
